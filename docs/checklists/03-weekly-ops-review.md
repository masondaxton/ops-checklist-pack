# 03 — Weekly ops review

Run once per week (30–40 minutes). Keep it boring and useful.

## Numbers (no vanity)

- [ ] Jobs completed vs promised
- [ ] Average response time to new inquiries
- [ ] Rework / return visits count
- [ ] Quotes sent vs won (or next-step rate if sales cycle is long)
- [ ] Cash collected vs invoiced (if applicable)

## Friction hunt

- [ ] Top 3 delays from the week (parts, access, approvals, no-shows)
- [ ] One process step to delete or automate next week
- [ ] One customer promise that slipped — root cause in one line
- [ ] Capacity check: are we overbooked for next week?

## Decisions

- [ ] Keep / change / stop one marketing or outreach action
- [ ] Assign owners for the top delay
- [ ] Schedule the next review on the calendar now

## Rule

If a metric cannot change an action next week, stop tracking it.
